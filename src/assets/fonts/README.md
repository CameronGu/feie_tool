FEIE Workpaper Sans is an offline PDF subset of Noto Sans Regular and Bold (Google, SIL Open Font License 1.1). Source: https://github.com/notofonts/noto-fonts . See public/licenses/NotoSans-OFL.txt. Base64 assets retain all 2,840 original cmap characters; hinting and unused OpenType shaping tables were removed with fonttools 4.66.1, and family names were changed for the derivative. coverage.json is the intersection of both bundled cmaps. Unsupported glyphs become [U+...] in PDF; clipboard and JSON retain original Unicode. Imported only by the lazy PDF module; no runtime system paths, remote fonts or added application dependency.
